# 3.3Vレギュレータの調査と修正

2026-10-26に回路図、基板、メーカー資料を照合した。

## 現在の採用品：AZ1117CH-3.3TRG1

秋月で単品を5個・10個買う前提の安価な品として、
[AZ1117CH-3.3TRG1（秋月116155）](https://akizukidenshi.com/catalog/g/g116155/)へ変更した。
確認時点で税込30円/個、5個150円、10個300円。数量値引きを仮定しない。
JLCPCB/LCSC番号はC92102で、PCBA向け部品表も更新した。

[Diodes公式データシート DS36676 Rev.5-2（2022-09）](https://www.diodes.com/assets/Datasheets/AZ1117C.pdf)
のSOT223/Hパッケージに基づき、1=GND、2とタブ=OUT、3=INとする。
SMDの `Package_TO_SOT_SMD:SOT-223-3_TabPin2` を維持する。
AP7361Cからのピン対応は旧1→新3、旧2→新1、旧3→新2。
回路図ではネットリスト比較で対応を確認し、基板はこの配列へ更新した。

セラミックコンデンサ対応で、データシートの出力容量下限は10µF、ESRは20Ω未満。
公称10µFのC4は公差・DCバイアスの余裕がないため、公称22µF、25V、X5Rへ変更した。
実効容量が使用温度・公差・3.3Vバイアス下で10µFを下回らないことは、最終部品評価で確認する。

安価な分、AP7361Cよりドロップアウトが大きい。SOT223は800mA時に標準1.2V、最大1.3V。
電気特性の規定入力差は1.5V以上であり、3.3V出力ではIC入力4.8V以上を設計目標とする。
5V公称だけではUSBケーブル・保護素子の電圧降下を含めた保証にならない。
低い入力電圧や大電流まで保証する製品にする場合は、元の低ドロップアウト品かDC/DCを再検討する。
1.35Aは標準電流制限値であり、連続1.35A供給能力とは扱わない。
損失・放熱の検証は引き続き必要。

新しい配列でU2を再配線するため、旧パッドへ接触する局所の電源配線・ビアを外した。
U2周辺以外の配線は維持し、交換前の設計は `pre-cheap-ldo-20261026.zip` に退避した。
以下はそれ以前の選定経緯。

## 見つかった問題

U2はLT1085-3.3だったが、回路図・基板にTO-92Lが割り当てられていた。
[Analog Devicesのデータシート](https://www.analog.com/media/en/technical-documentation/data-sheets/1083ffe.pdf)
に記載されるLT1085-3.3のTO-220・DDなどのパッケージと一致しない。
ERCはパッケージの適合を保証しないため、ERCが0件でも実装できる組合せではなかった。

LT1085の固定3.3V品は1=GND、2=OUT、3=IN。
フル負荷時のドロップアウト最大値は1.5Vであり、5V入力では電圧降下への余裕が小さい。
これは軽負荷でも常に動かないという意味ではないが、USB電源用途として部品を見直した。

## 以前の採用部品（変更前）

[AP7361C-33E-13 / JLCPCB C500795](https://jlcpcb.com/partdetail/DiodesIncorporated-AP7361C_33E13/C500795)
へ変更した。3.3V固定、1A定格、入力範囲2.2〜6V、SOT-223のLDO。
[Diodesデータシート DS37274 Rev.5-2（2020-10）](https://www.diodes.com/datasheet/download/AP7361C.pdf)
で、ピン配列、入出力容量、セラミックコンデンサへの対応を確認した。

| 端子 | 接続 |
| --- | --- |
| 1 IN | +5V |
| 2 GND・放熱タブ | GND |
| 3 OUT | +3.3V |

KiCadシンボルは `Regulator_Linear:AP7361C-33E`、フットプリントは
`Package_TO_SOT_SMD:SOT-223-3_TabPin2`。
同名末尾にRが付くAP7361C-33ERはピン配列が違うため、そのまま代替しない。
旧U2からの置換では、GNDを旧1→新2、OUTを旧2→新3、INを旧3→新1へ対応させた。
ネットリストをこの対応で比較し、他の接続が変わっていないことを確認した。

入力はC1=2.2µFとC2=100nF、出力はC4=10µFのセラミックを使用する。
メーカー指定の入力1µF以上・出力2.2µF以上を基準とし、PCBでは各コンデンサを
対応する端子の近くに配置する。容量はDCバイアス・温度・公差で変わるため、
公称値だけで判断せず実効容量を確認する。

## 残る確認

1AはICの定格であり、この未配線基板での連続供給能力の保証ではない。
5V→3.3Vの損失は概算で `1.7 × 負荷電流` Wとなり、300mAで0.51W、
500mAで0.85W、1Aで1.7W。周囲温度、GNDタブの放熱銅箔、基板構成を決め、
接合温度と無線送信時の電圧変動を確認する必要がある。
必要な連続電流や温度条件によっては降圧DC/DCへの変更を検討する。

カメラは既存の+5Vから給電され、3.3Vレギュレータを通らない。
USB入力側の電流予算にはESP32側とカメラ側の両方を含める。
USB電源の電流広告の検出、過電流・逆流対策や実機での給電検証は今回実装していない。
3.3Vレールの追加デカップリングを含むESP32全体の電源設計も、最終レイアウト時に確認する。
